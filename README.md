Employee Attrition and Salary Prediction using IBM HR Analytics Dataset

This project focuses on applying Data Science and Machine Learning techniques to analyze employee attrition and predict employee salaries using the IBM HR Analytics Employee Attrition dataset. The objective is to identify the main factors influencing employee turnover and build predictive models that help organizations improve employee retention and salary estimation.

The project includes:

Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Data visualization and correlation analysis
Feature engineering and encoding
Employee attrition prediction using classification algorithms
Salary prediction using regression models
Model evaluation and performance comparison

Technologies and tools used:

Python
Pandas & NumPy
Matplotlib & Seaborn
Scikit-learn
Jupyter Notebook

The results provide insights into employee behavior, work satisfaction, income distribution, and the factors that contribute most to attrition within a company.
